# Meeting notes

One short file per meeting that mattered to the design. Not minutes: just what changes the work.

## Rules

- **File name:** `YYYY-MM-DD-<short-slug>.md`, for example `2026-01-12-kickoff-call.md`. Copy `_template.md`.
- **Keep:** a condensed summary, decisions made, open questions, and design action items with owners.
- **Leave out:** transcripts, chit-chat, and anything that doesn't change the work.
- **Source:** say where the notes came from (your own notes, a recording summary, or a note-taking tool). Summaries can leave things out. Say so if you suspect it.
- **Notes are inputs, not decisions.** When a meeting settles something, offer to write it in `../../decisions/`. When it raises a question, offer to add it to `../../product/open-questions.md`.
- Add a row to `../README.md`? Not needed per meeting. Only link meetings from the files they influenced.

## Who decides which meetings to save

The designer does. If you're not sure, ask: "Should I save a summary of this one?"
